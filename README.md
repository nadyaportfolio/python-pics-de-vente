# Saisonnalité des ventes de fruits et légumes

**Outil** : Python (pandas, statsmodels, scipy) · **Projet 9** · FastAlim

**Objectif** : anticiper les pics de demande pour adapter les stocks et l'entrepôt.

**Démarche**
- Contrôle des données : 21 915 lignes, série complète et continue
- Décomposition des séries et coefficients saisonniers
- Tests ANOVA, Kruskal-Wallis, Pearson et Spearman

**Résultats**
- CA de 2 M€ (2019-2022), dont 47 % réalisés par le top 5
- 3 profils : pic en été (tomate, abricot), en hiver (kiwi), stable (pomme, banane)

**Recommandations**
- Organiser l'entrepôt en zones selon les profils saisonniers
- Prévoir les approvisionnements mensuels avec les coefficients saisonniers

**Compétences** : analyse de saisonnalité avec des séries temporelles
